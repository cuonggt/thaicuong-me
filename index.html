01gossh client2026

omassh on GitHub

A keyboard-driven SSH client for the terminal: Termius’s data model, lazygit’s interaction model, running on top of real OpenSSH.

Keep hosts in groups that share a user, a key and a jump host. Connect with a keystroke, full screen or in a pane beside the list. Browse files, keep tunnels up after you quit, and run a script across a whole group — all through the ssh already on your machine.

$brew install --cask cuonggt/tap/omassh

02goweb framework2026early

tug on GitHub

A web framework for Go apps whose frontend is Inertia.js: React, Vue or Svelte pages rendered with props straight from Go handlers, no API in between, and the whole app shipped as one binary.

Background jobs on a schedule, server-side rendering, migrations in plain SQL, uploads on disk or in S3, mail, and events broadcast to every open page. tug gen types the frontend against the Go — props, routes and forms — and tug new -auth starts an app with accounts, passkeys, API tokens and two-factor logins.

The name: a tugboat is small, and moves ships many times its size.

$go install github.com/cuonggt/tug/cmd/tug@latest

03goserver console2026

rove on GitHub

A terminal console for the Linux servers you already reach over SSH. If ssh server works, rove works.

It reads ~/.ssh/config and never asks for a private key. See every server at once, then find what’s wrong — processes and their containers, disks, services, listeners — without remembering the Linux commands for each.

$brew install --cask cuonggt/tap/rove
  • Releases

04shellmacos setup2024

omakma on GitHub

An opinionated setup for macOS, heavily inspired by Omakub. One command turns a fresh Mac into a fully configured, modern web development system.

Ghostty, Alacritty and iTerm2; Neovim with LazyVim; tmux and Zellij; lazygit, fzf, ripgrep, bat, eza and zoxide; Node, Go, Python, Ruby, PHP and Rust; MySQL, PostgreSQL and Redis if you want them. Afterwards, omakma opens a menu for themes, fonts and the rest.

$bash < <(curl -sL https://raw.githubusercontent.com/cuonggt/omakma/master/boot.sh)

About

I’m Cuong Giang, a software developer in Hà Nội. I’ve kept my work on GitHub since 2014 and have published open source since 2016: Ruby gems for Rails at first, then Laravel packages, and lately mostly Go.

A lot of what I build carries a good idea somewhere new. Stripe billing in the style of Laravel Cashier, for Rails. Laravel’s Envoy, as one Go binary. husky’s git hooks, for PHP. Omakub’s opinions, for the Mac. Inertia.js, for Go.

The rest lives between a laptop and a server: an SSH client, deploy tools, and a console for a fleet of Linux machines.
